### Issue #2: "Row-level security policy violation" - RESOLVED ✅
**Error:** Upload failed with RLS policy violation

**Root Cause:** Android app uses anon key (`sb_publishable_...`) instead of user token during upload

**Solution:** Created permissive storage policies for debugging
```sql
-- Allow ANYONE to upload to avatars bucket
CREATE POLICY "Avatars Anon Upload" ON storage.objects
FOR INSERT WITH CHECK (bucket_id = 'avatars');

-- Allow public read
CREATE POLICY "Avatars Public Read" ON storage.objects
FOR SELECT USING (bucket_id = 'avatars');
```

### Issue #3: Profile creation RLS policy - RESOLVED ✅
**Error:** Profile creation failed with RLS violation

**Solution:** Added proper RLS policies for profiles table
```sql
-- Allow authenticated users to insert their own profile
CREATE POLICY "Users insert own profile" ON profiles
FOR INSERT
WITH CHECK (
  auth.role() = 'authenticated' AND
  id = auth.uid()
);

-- Allow authenticated users to view all profiles
CREATE POLICY "Users view profiles" ON profiles
FOR SELECT
USING (auth.role() = 'authenticated');

-- Allow authenticated users to update their own profile
CREATE POLICY "Users update own profile" ON profiles
FOR UPDATE
USING (
  auth.role() = 'authenticated' AND
  id = auth.uid()
);
```
