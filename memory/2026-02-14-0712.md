## 📱 Application Flow

### 1. **Splash Screen** → Check Session
```
SplashScreen
  ├─ Check if user logged in (SessionManager)
  ├─ If logged in:
  │   ├─ Get saved role (worker/business)
  │   ├─ Get current step (onboarding progress)
  │   └─ Navigate to appropriate screen
  └─ If not logged in:
      └─ Navigate to "role_selection"
```

### 2. **Role Selection**
```
RoleSelectionScreen
  ├─ Worker → "worker_welcome"
  ├─ Business → "business_welcome"
  └─ Login → "login"
```

### 3. **Login Flow**
```
LoginScreen
  ├─ Email/Password authentication
  ├─ Success → Check role → Navigate to dashboard
  └─ Failed → Show error toast
```

## 👷 Worker Registration Flow

```
worker_welcome
  └─ Click "Get Started" → worker_registration

worker_registration
  ├─ Full Name
  ├─ Email
  ├─ Password
  ├─ Phone Number
  ├─ Submit → registerWorker()
  ├─ Creates Supabase Auth user
  ├─ Creates profile record
  └─ Success → worker_basic_profile

worker_basic_profile
  ├─ Job Category (Housekeeping, Kitchen, etc.)
  ├─ Job Role (Staff, Supervisor, Manager)
  ├─ Avatar Photo Upload → "avatars" bucket ✅
  ├─ Update worker_profile
  └─ Next → worker_document_upload

worker_document_upload
  ├─ ID Card Photo → "id_cards" bucket ✅
  ├─ Selfie Photo → "selfies" bucket ✅
  └─ Next → worker_face_verification

worker_face_verification
  ├─ Real-time face capture (verification)
  └─ Next → worker_address_verification

worker_address_verification
  ├─ Full Address
  ├─ Province/City/District/Postal Code
  ├─ Address Photo → "address_verification" bucket ✅
  ├─ Domicile Document → "address_verification" bucket ✅
  ├─ Location coordinates
  └─ Next → worker_experience_level

worker_experience_level
  ├─ Experience Level (Junior/Senior/Expert)
  ├─ Years of Experience
  ├─ Experience Document → "portfolio" bucket ✅
  └─ Next → worker_skill_selection

worker_skill_selection
  ├─ Select skills (Cleaning, Cooking, etc.)
  ├─ Skill experience levels
  └─ Next → worker_portfolio_upload

worker_portfolio_upload
  ├─ Upload portfolio photos → "portfolio" bucket ✅
  ├─ Multiple files allowed
  └─ Next → worker_verification_pending

worker_verification_pending
  ├─ Wait for admin approval
  └─ Approved → worker_home
```

## 🔍 Tables & Endpoints Used

### Authentication
- `/auth/v1/token` - Login with email/password
- `/auth/v1/signup` - Register new user
- `/auth/v1/logout` - Logout user

### Profiles
- `profiles` table
  - `SELECT` - Get user profile
  - `INSERT` - Create profile after registration
  - `UPDATE` - Update profile information

### Worker Profiles
- `workers` table
  - `SELECT` - Get worker profile
  - `UPDATE` - Update worker details
  - Columns: job_category, job_role, avatar_url, skills, experience_level, etc.

### Business Profiles
- `businesses` table
  - `SELECT` - Get business profile
  - `UPDATE` - Update business details
  - Columns: business_name, category, logo_url, address, facilities, etc.

### Jobs
- `jobs` table
  - `SELECT` - Get all jobs / get by ID
  - `INSERT` - Post new job (business only)
  - `UPDATE` - Update job details
  - `DELETE` - Delete job (business only)

### Job Applications
- `job_applications` table
  - `SELECT` - Get applications (worker own / business for their jobs)
  - `INSERT` - Apply for job (worker)
  - `UPDATE` - Update application status (accept/reject)

### Job Assignments
- `job_assignments` table
  - `SELECT` - Get assignments
  - `UPDATE` - Update assignment status

### Wallets
- `wallets` table
  - `SELECT` - Get wallet balance
  - `UPDATE` - Update wallet balance (system)

### Wallet Transactions
- `wallet_transactions` table
  - `SELECT` - Get transaction history
  - `INSERT` - Create transaction (system)

### Storage
- `avatars` bucket - Profile photos
- `verification_documents` bucket - Verification docs
- `address_verification` bucket - Address proof
- `portfolio` bucket - Portfolio images
- `documents` bucket - Business documents
- `verification` bucket - Location verification
- `id_cards` bucket - Worker ID cards
- `selfies` bucket - Worker selfies

## ⚠️ Potential Issues (Monitor)

### 1. Profile Auto-Creation
**Status:** Not implemented  
**Risk:** Workers/businesses without profile records  
**Mitigation:** App should call `create_missing_profile()` after registration

### 2. Auth Triggers
**Status:** Not deployed (permission issue)  
**Workaround:** Manual profile creation in app layer  
**Impact:** Low - workaround works

### 3. JVM Testing
**Status:** Blocked (Android context requirement)  
**Workaround:** Use instrumented tests (connectedAndroidTest)  
**Impact:** Medium - tests run slower but functional

### 4. Storage Token Passing
**Status:** Uploads use anon key (workaround applied)  
**Issue:** Token retrieved but not passed to Supabase client  
**Workaround:** Permissive policies allow anon uploads  
**Long-term:** Fix `uploadImage()` to pass auth token properly
