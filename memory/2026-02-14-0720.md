# Database Schema Mismatch - worker_profiles vs workers

**Date:** 2026-02-14  
**Issue:** App uses `worker_profiles` table, but database has `workers` table

---

## Problem

**Error from David:**
```
Could not find table 'public.worker_profiles' in the schema cache
URL: https://supabase-dev.dailyworkerhub.com/rest/v1/worker_profiles?user_id=eq.276c369e...
```

**Root Cause:**
- App code queries `worker_profiles` table
- Database has `workers` table (not `worker_profiles`)
- App uses `user_id` filter, but table has `id` column
