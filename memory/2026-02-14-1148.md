## **Problem:**

**Kenapa login redirect ke register?**

Karena `login()` function di SupabaseRepository **tidak save role dan step** setelah login berhasil!

---

## **Logic Masalah:**

### **Login Function (Sebelum - BROKEN):**
```kotlin
suspend fun login(context: Context, email: String, password: String): Result<String> {
    // ... auth success ...
    SessionManager.saveSession(context, accessToken, userId)  // ❌ Hanya save token + user ID
    Result.success(userId)
}
```

### **Splash Screen Logic:**
```kotlin
if (token != null) {
    navController.navigate(savedStep ?: "role_selection") {  // ❌ savedStep null!
        popUpTo("splash") { inclusive = true }
    }
} else {
    navController.navigate("role_selection")  // ❌ Ke sini
}
```

**Result:** Splash screen tidak tahu role dan step, jadi default ke `role_selection` → muncul seperti register lagi!

---

## ✅ Solution Applied:

### **Login Function (Sesudah - FIXED):**
```kotlin
suspend fun login(context: Context, email: String, password: String): Result<String> {
    // ... auth success ...
    SessionManager.saveSession(context, accessToken, userId)
    
    // ✅ Fetch role dari profiles
    val profile = client.from("profiles").select() {
        filter { eq("id", userId) }
    }.decodeSingle<Map<String, Any?>>()
    
    val role = profile["role"] as? String ?: "worker"
    SessionManager.saveSelectedRole(context, role)  // ✅ Save role
    
    // ✅ Set step berdasarkan verification_status
    val verificationStatus = profile["verification_status"] as? String ?: "pending"
    val step = if (verificationStatus == "verified") {
        if (role == "worker") "worker_home" else "business_home"
    } else {
        if (role == "worker") "worker_basic_profile" else "business_basic_profile"
    }
    SessionManager.saveCurrentStep(context, step)  // ✅ Save step
    
    Result.success(userId)
}
```
